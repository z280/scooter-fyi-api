Scheduler

Every scheduled operation, what it is supposed to do, and what it last actually did. The schedule lives in the scheduler container, which runs supercronic against the crontab below. Container TZ is America/Denver, so the 9 AM daily jobs are DST-aware.

Operations

Schedule is parsed out of the active crontab; last run comes from the job-run ledger, which every command writes through src/cli.py's single dispatch point. A row with a schedule but no run has never fired since the ledger existed — that is the row worth looking at, so those sort first, then failures, then by recency.
